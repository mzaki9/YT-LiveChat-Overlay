```text
tidy(codebase)
  |> inspect()
  |> identify(duplicate_configuration)
  |> identify(duplicate_dependencies)
  |> identify(duplicate_build_systems)
  |> identify(duplicate_entrypoints)
  |> identify(dead_files)
  |> identify(dead_code)
  |> identify(unused_dependencies)
  |> identify(unused_scripts)
  |> identify(unnecessary_config)
  |> identify(unnecessary_directories)
  |> identify(legacy_artifacts)

  |> consolidate(
       package_managers,
       package_manifests,
       build_configuration,
       compiler_configuration,
       lint_configuration,
       formatter_configuration,
       test_configuration,
       environment_configuration,
       entrypoints
     )

  |> enforce(
       one(package_json),
       one(package_manager),
       one(build_system),
       one(primary_entrypoint),
       one(source_structure)
     )

  |> remove(
       unused_files,
       unused_dependencies,
       unused_scripts,
       duplicate_config,
       obsolete_config,
       generated_artifacts,
       temporary_files,
       abandoned_implementations,
       legacy_files
     )

  |> simplify(
       directory_structure,
       scripts,
       configuration,
       dependencies,
       build_process
     )

  |> preserve(
       functionality,
       public_api,
       runtime_behavior,
       required_configuration
     )

  |> verify(
       install,
       build,
       test,
       lint
     )

  |> output(clean_repository)
```

### Repository Invariants

```text
repository
  |> require(
       exactly_one(package_json),
       exactly_one(lockfile),
       exactly_one(build_pipeline),
       exactly_one(primary_source_root),
       exactly_one(primary_entrypoint)
     )

  |> reject(
       duplicate_package_manifests,
       duplicate_lockfiles,
       multiple_build_systems,
       competing_configurations,
       abandoned_source_trees,
       unused_dependencies,
       dead_files
     )
```

### Package Management

```text
dependencies
  |> inspect()
  |> remove(unused)
  |> deduplicate()
  |> consolidate()

package_management
  |> use(one_package_json)
  |> use(one_package_manager)
  |> use(one_lockfile)

do_not:
    create_additional_package_json()
    keep_old_package_json()
    keep_duplicate_lockfiles()
    keep_multiple_dependency_manifests()
```

### Build System

```text
build
  |> identify(all_build_tools)
  |> choose(existing_canonical_build)
  |> remove(redundant_build_tools)
  |> remove(duplicate_build_scripts)
  |> remove(legacy_build_configuration)
  |> expose(one_clear_build_command)
```

The repository should have a simple mental model:

```text
install()
    |> dependencies()

build()
    |> source()
    |> compiler()
    |> output()

test()
    |> source()

lint()
    |> source()
```

Avoid multiple ways of doing the same thing.

```text
build()
build:legacy()
build:old()
build:v2()
build:dev()
build:production()
```

should not exist unless each command has a **real and documented purpose**.

### Configuration

```text
configuration
  |> find(all_config_files)
  |> classify(required, duplicate, obsolete)
  |> consolidate()
  |> remove(obsolete)
```

Prefer:

```text
one source of truth
```

over:

```text
config/
config.old/
config.backup/
config.local/
config.new/
config.final/
```

Do not preserve configuration merely because it already exists.

If two configurations serve the same purpose:

```text
choose(canonical)
  |> migrate(required_settings)
  |> delete(duplicate)
```

### Files

```text
files
  |> inspect()
  |> classify(
       required,
       referenced,
       generated,
       unused,
       obsolete,
       duplicate
     )

  |> keep(
       required,
       referenced
     )

  |> remove(
       unused,
       obsolete,
       duplicate
     )
```

Before deleting a file:

```text
if referenced(file):
    keep(file)

if generated(file):
    keep_only_if_required_by_workflow()

if unused(file):
    delete(file)

if duplicate(file):
    consolidate_then_delete(file)
```

Do not keep files "just in case".

---

### Directory Structure

```text
directories
  |> remove(empty)
  |> remove(duplicate_responsibilities)
  |> merge(similar_purposes)
  |> simplify()
```

Avoid structures such as:

```text
src/
src-old/
src-new/
src-v2/
legacy/
backup/
tmp/
temp/
```

unless they have an explicit purpose.

There should be **one canonical implementation**.

### Scripts

```text
scripts
  |> inspect()
  |> identify(duplicates)
  |> identify(dead_scripts)
  |> identify(unclear_scripts)
  |> remove(dead)
  |> merge(duplicates)
  |> rename(unclear)
```

Prefer:

```text
dev
build
test
lint
format
```

over a large collection of scripts that perform overlapping tasks.

### Dead Code

```text
codebase
  |> find(unreachable_code)
  |> find(unused_exports)
  |> find(unused_functions)
  |> find(unused_types)
  |> find(commented_out_code)
  |> find(legacy_implementations)
  |> remove()
```

Do not keep commented-out implementations as historical backups.

Use version control for history.

```text
git = history
codebase = current_truth
```

### Duplicate Implementations

```text
when(similar_implementations_exist):

    compare(implementations)
      |> identify(canonical)
      |> migrate(required_behavior)
      |> delete(redundant_implementation)
```

Do not maintain:

```text
foo()
fooV2()
newFoo()
legacyFoo()
fooNew()
```

when they represent the same responsibility.

There should be one obvious implementation.

---

### Cleanup Principle

```text
tidy(codebase)
  |> reduce(number_of_files)
  |> reduce(number_of_dependencies)
  |> reduce(number_of_configurations)
  |> reduce(number_of_build_paths)
  |> reduce(number_of_entrypoints)
  |> reduce(number_of_ways_to_do_the_same_thing)
```

But:

```text
less_files != better
less_dependencies != better
less_abstraction != better
```

Only remove something when it is:

```text
unused
duplicate
obsolete
redundant
unnecessary
```

### Safety

```text
before(remove(file)):
    verify(not_required)

before(remove(dependency)):
    verify(not_imported)
    verify(not_used_by_scripts)
    verify(not_required_at_runtime)

before(remove(config)):
    verify(not_referenced)

before(merge(build_system)):
    verify(build_output_equivalent)

after(tidy):
    run(install)
    run(build)
    run(test)
    run(lint)
```

Never delete something merely because it *looks* unused without checking its references and tooling usage.
